# Lasers & Feelings
 
## Background
Lasers & Feelings is a quick-play roleplaying game, based on the songs of The Doubleclicks.
> *You are the crew of the interstellar scout ship Raptor. Your mission is to explore uncharted regions of space, deal with aliens both friendly and deadly, and defend the Consortium worlds against space dangers. Captain Darcy has been overcome by the strange psychic entity known as Something Else, leaving you to fend for yourselves while he recovers in a medical pod.*

## Introduction
A GM (Game Master) leading a Lasers & Feelings game needs a software to run the game smoothly. It must have the ability to roll dices. Additionally, it could also be better with a feature such as managing character information, ship status, having random adventures and add-ons related to the gameplay.

## Dictionary
- **Game Master**: The person managing and running a *Lasers & Feelings* session.
- **Player**: A participant controlling a single crew member aboard the ship *Raptor*.

## Requirements
### User Stories
- **Game Master**: As a GM, I want to generate a random adventure prompt combining threat, target, obstacle, and climax so that I can quickly start a game session without manual table lookup.
- **Game Master**: As a GM, I want to track ship status and enemy threat levels during an encounter so that all players have a clear, shared understanding of the current game state.

- **Player**: As a player, I want to select my character style, role, and core Number (2–5) so that my character sheet is generated with calculated stats and also declaring whether my action uses Lasers or Feelings and roll d6 dice so that the system automatically evaluates my successes or triggers a LASER-FEELINGS state.
- **Player**: As a player, I want to create and save my character information sheet (including name, style, role, and Number) so that my character details are accessible during play.
